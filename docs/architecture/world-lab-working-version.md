# Рабочая версия World Lab

## Открыть

- `/world` — карта девяти логических секторов, перетаскивание мест, маршруты, привязки NPC.
- `/economy` — счета, товары, начальные запасы, переработка и предложение жилья.
- `/simulation` — одно ядро Godot Web, управление временем, выбор NPC, причины действий, журнал и снимки.

Кнопка «Сохранить мир» сохраняет определения в общий авторский проект с проверкой revision. Изменённый черновик не попадает в запущенную симуляцию. Новый запуск фиксирует собственные определения и SHA-256. Результат никогда не записывается обратно в анкеты.

Начальные деньги и цены — явно тестовые. Город на рисунке не считается Ровенвудом. Ферма Мартина отделена от фермы игрока. Начальный прогон содержит Тео, Мартина и Гидеона; других персонажей можно подключать через раздел привязок. Рабочие точки, роли, счета, зарплата, аренда, маршруты и баланс задаются в редакторах.

## Что уже происходит

- NPC выбирают действия по потребностям, рабочему окну, доступному грузу и цели жилья.
- План включает переход по кратчайшему открытому пешему маршруту и исполнение действия. Текущее действие не переключается каждую минуту.
- Работа занимает время; зарплату списывает счёт работодателя один раз за день после нужного труда.
- Питание покупает и расходует реальные запасы картофеля; аренда переводит деньги таверне.
- Ферма перерабатывает существующую пшеницу в муку. Это прототип переработки, не полная агросимуляция; бесплатный урожай за смену не создаётся.
- Тео забирает реальный груз, идёт с ним в таверну, передаёт после оплаты. Если денег нет — возвращает груз по маршруту.
- Дом покупается только при достаточных средствах и доступном продавце; меняются владелец, жильё NPC и цель. Последующая работа продолжается.
- Разговор создаётся при совместной доступности двоих; у участников обновляются отношения.
- Журнал содержит решения с причинами и оценками альтернатив. Наблюдатели получают только доступные им события; внутренние решения знает сам NPC.
- При исчерпании запасов таверна может купить ограниченное количество еды у внешнего рынка: запас продавца конечен и деньги списываются.
- Сохраняются защищённые авторские факты. Нет автоматической переписи истории семьи или романтических анкет.

## Хранение

- `project.world`: авторские определения в существующем `studio_projects.main` с revision/CAS. Старый клиент, не знающий world, не стирает его на сервере.
- IndexedDB `farlands-world-runs`: последний локальный снимок для продолжения на устройстве.
- Приватный Supabase Storage `studio-world-runs`: отдельные неизменяемые снимки UUID по кнопке; доступ через `/api/simulation`, с той же авторизацией, что у проекта. До 100 последних снимков в списке.
- JSON отчёта включает определения, хеш, время, состояние, RNG, грузы, счета, запасы, события и ledger операций. При восстановлении проверяются версия, ссылки, хеш и балансы.

## Одно ядро

Канонический источник `simulation/world_core.gd`. Web-движок и исходники собираются `npm run build:simulation` (переменная GODOT — исполняемый файл 4.7.1). `npm run build` проверяет, что источники и скомпилированный PCK не разошлись. Расчёт TypeScript не дублирует GDScript: Vue только отображает и проверяет данные.

В редакторе есть «Пакет мира для Godot»: определения, manifest, то же ядро, сервис времени/сохранения, отладочная проекция и отдельный стенд. Скрипт установки:

```
node tools/install-game-simulation.mjs <путь-к-игровому-проекту>
```

Он добавляет WorldSimulation после GameClock, не заменяет существующий world/definition.json. Для обновления авторских данных экспортируйте свежий пакет. Сервис слушает minute_passed и day_changed; ранний сон рассчитывает весь пропущенный интервал. SaveGame сохраняет все состояния NPC через постоянный сервис. Данные результатов и визуальные узлы разделены.

## Проверки

```
npm run build
npm test
npm run test:e2e
node tools/test-simulation.mjs
node tools/test-clock-integration.mjs
```

Проверяются: реальный браузерный Godot под CSP, совпадение с native/headless, 30 дней сохранения денег/товаров, отсутствие производства без сырья, закрытые дороги, знания свидетелей, снимок/продолжение, разная величина шага, сон с настоящим GameClock и общий SaveGame, ближняя/дальняя отладочная проекция, экспорт ZIP и сохранение старых анкет.

## Границы первой версии

Это рабочий вертикальный срез для настройки и испытания небольших групп NPC, а не законченный движок всей экономики. Один запуск ограничен 30 днями, отчёт облака — 3,5 МБ. UI показывает последние 100 подходящих записей, JSON содержит весь журнал. Web-ядро загружает около 40 МБ при первом открытии; вычисления локальны и не обращаются к Gemini.

В этой версии используются пешие маршруты, одна переработка, один тип еды и одно предложение жилья; лодка/повозка уже задаются как данные маршрута, но отдельное исполнение движения ими не реализовано. Нет полной романтической симуляции, сельхозпроизводства NPC по всем сезонам или универсального HTN всех профессий. Продвинутая память/слухи требуют следующих итераций. Производственные и денежные операции не подменяют существующие игровые инвентари: мост к production-интерактивным объектам и реальной навигации требует назначения anchors и правил владения.

`world_actor.gd` — отладочное ближнее отображение логического пути, не готовый NavigationAgent для production-карты. Сейчас можно запускать стенд и проверять единое состояние; окончательные дороги, город и здания проектируются отдельно. Веб-сервис не является обязательным сервером игры: экспортированное ядро работает офлайн в Godot.
