# Ядро мира FARM & FARLANDS

Правила 9 поддерживают многоэтапные просьбы (состояние life v2): каждый разговор подтверждает отдельный этап, доклад требует реального разговора с просителем. Старые просьбы v1 сохраняют прежний единственный шаг; этапы не добавляются к ним задним числом. Денежных наград и нового таймера квестов нет.

1. Распакуйте addons/farlands_world/ и world/ в игровой проект Godot 4.7.1.
2. Добавьте autoload WorldSimulation: res://addons/farlands_world/world_service.gd после GameClock.
3. Откройте res://addons/farlands_world/world_lab.tscn для условного отладочного стенда.
4. Общее сохранение SaveGame включает WorldSimulation как участника saveable. Его снимок содержит всех NPC, независимо от наличия физического узла.
5. Для обычного тестового прогона без игровых сцен используйте отдельный проект simulation/ из репозитория Studio: Godot --headless --path simulation --script run.gd -- world.json report.json 10080.

Ядро в Web и игре — один набор world_core.gd + mechanics.gd + life.gd. Временные шаги идут от GameClock; сон обрабатывается через day_changed с расчётом пропущенных минут. Второго игрового таймера нет. Загрузка общего слота должна восстановить и game_clock, и world_simulation. Необязательный жизненный слой фиксирует направленные отношения, просьбы, цели, денежные изменения и смену дома; он выключен, пока автор явно не настроит definition.life.

Стартовые деньги, производство и предложение жилья — тестовый баланс. Локации города условны. world_actor.gd — отладочная проекция логического пути; физическую навигацию по production-картам ещё нужно привязать к реальным anchors и NavigationAgent. Не включайте WanderComponent и эту проекцию как двух владельцев положения одного NPC.

При изменении исходных world_core.gd / mechanics.gd / life.gd в Studio выполните npm run build:simulation и повторно экспортируйте пакет. build.json содержит контрольные суммы. Не редактируйте независимую копию ядра в игре.

Подключаемые механики v1 описываются в definition.mechanics. Их значения, версии и незавершённые действия входят в снимок. Системные потребности и экспериментальная кухня сохранены; неизвестные версии модулей отклоняются. Подробный контракт — docs/architecture/mechanics-contract.md в репозитории Studio.
